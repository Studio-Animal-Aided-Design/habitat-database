# Manuelle M1-Abnahme: CI-Ergänzung

Diese Änderung versioniert die zwei für #113 relevanten Fälle der bestehenden [M1-UAT-Suite #123](https://github.com/Studio-Animal-Aided-Design/habitat-database/issues/123). Die GitHub-Spiegel und das [M1-UAT-Projekt](https://github.com/orgs/Studio-Animal-Aided-Design/projects/2) bleiben die Ausführungsverfolgung für die gesamte Suite.

| ID | Szenario | GitHub | Zustand |

| [UAT-M1-018](UAT-M1-018.md) | Editorial UI, responsive Darstellung und grundlegende Bedienbarkeit | [#141](https://github.com/Studio-Animal-Aided-Design/habitat-database/issues/141) | Vollständiger Fall nicht ausgeführt; lokale CI-Stichproben dokumentiert |
| [UAT-M1-023](UAT-M1-023.md) | Studio-CI und ausdrückliche Designfreigabe | [#146](https://github.com/Studio-Animal-Aided-Design/habitat-database/issues/146) | Blockiert bis benannte Freigabe und IONOS-RC verfügbar sind |

Die [lokale Designgalerie](../../design/113/index.html) ist Evidenz für den Entwurf, keine Kundenfreigabe. Jeder tatsächlich ausgeführte Fall benötigt Datum, prüfende Person, Umgebung/URL, Revision, Daten-Prüfsumme, Browser/Viewport, Soll/Ist-Ergebnis, redigierte Screenshots und gegebenenfalls ein verlinktes Defektticket. Fehlende Voraussetzungen ergeben **Blockiert**, nicht **Bestanden**. Die endgültige M1-Entscheidung bleibt in #115.
